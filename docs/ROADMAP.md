## R3 — Numerical relativity

- Export admissible initial data to an external 3+1 evolution framework.
- Add constraint monitoring, convergence order and independent-code comparison.
- Keep evolution results separate from analytic registry expectations.

## R4 — Observational interface

- Define preregistered quasinormal-mode and echo observables.
- Validate the inference pipeline on injections and ordinary black-hole
  negative controls before examining observational data.
- Never convert a waveform anomaly directly into a CTC claim.

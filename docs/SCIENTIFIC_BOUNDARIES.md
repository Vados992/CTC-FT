# Scientific Boundaries

## Permitted statements

- A registered mathematical model passed or failed specified software gates.
- A particular closed orbit is a witness within its declared model, domain,
  topology, mode and approximation.
- A common temporal function certifies causality for the modes and domain that
  were actually covered.
- A parameter boundary was reproduced to the recorded numerical tolerance.

## Prohibited promotions

- `g_phiphi < 0` alone is not a universal CTC theorem.
- Failure of a numerical search is not evidence of absence.
- A sector certificate is not a global certificate.
- A solution result is not automatically a theory-wide result.
- Passing software tests is not experimental validation.
- Mathematical admission of a CTC is not physical constructibility.
- This repository does not demonstrate a real time machine.

## Known incomplete areas

Rotating k-essence, perturbative EdGB, generic Horndeski characteristics,
backreacting semiclassical evolution, full numerical-relativity integration
and gravitational-wave inference remain unimplemented or external. Their
presence in documentation is a specification, not an execution result.

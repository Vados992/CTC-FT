# Security and Scientific-Integrity Reports

Report code-execution vulnerabilities through GitHub's private vulnerability
reporting mechanism when available. Do not disclose exploitable details in a
public issue before a fix exists.

Scientific-integrity defects—wrong signs, invalid domains, missing topology,
overstated claim levels, unreproducible tests or provenance errors—may be filed
as public issues with a minimal reproducer and primary-source citation.

Supported branch: `main` at version 2.1.x.
